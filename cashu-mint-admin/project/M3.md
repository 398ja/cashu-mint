# M3 Mint Status and Health

## Overview
Enable visibility into the operational state and performance of mints.

## Deliverables
- Dashboards and APIs showing issued tokens, redemptions, and reserve levels.
- Status endpoints for uptime and performance monitoring.

## Tasks
1. Collect and store real-time and historical metrics.
2. Build monitoring views and API responses.
3. Integrate with external observability tools when available.
4. Test metric accuracy and endpoint reliability.

## Considerations
- Metrics should support alerting and capacity planning.
- Protect sensitive data while exposing health information.
