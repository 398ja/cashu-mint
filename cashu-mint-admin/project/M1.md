# M1 Mint Lifecycle Management

## Overview
Establish the administrative foundation to create and control mint instances.

## Deliverables
- CRUD APIs and UI flows for creating, updating, pausing, resuming, and retiring mints.
- Support for applying reusable configuration templates at creation time.

## Tasks
1. Design mint instance schema and persistence layer.
2. Implement lifecycle endpoints and integrate with authentication.
3. Add configuration template repository and selection logic.
4. Cover main flows with unit and integration tests.

## Considerations
- Ensure validation of parameters and proper error handling.
- All operations must be auditable.
