# M1 Mint Lifecycle Management (CLI Phase)

## Overview
Focus exclusively on the command-line workflows that create and control mint instances. The CLI must stand on its own for day-one
operators; any web experience will be scheduled only after this milestone is accepted.

## Technical analysis alignment
- The [core protocol services](../../docs/explanations/technical-analysis.md#core-protocol-services) section maps the minting,
  melting, and swap task orchestration that lifecycle commands must drive end to end.
- Address the durability gap called out under [risks and recommendations](../../docs/explanations/technical-analysis.md#risks-and-recommendations)
  so CLI operations can rely on persistent signature recovery during rollbacks.

## Deliverables
- Domain model and storage schema for mint instances, templates, environment bindings, and lifecycle history.
- CLI subcommands (`mint create`, `mint update`, `mint pause`, `mint resume`, `mint retire`) with JSON/YAML input support and dr
y-run validation.
- Event log entries that capture lifecycle transitions and expose them through API and CLI views.
- RBAC-protected REST/command handlers that allow scripted and interactive CLI execution.
- Documentation and examples showing automated and guided terminal flows for lifecycle management.

## Tasks
1. Design the lifecycle state machine, persistence schema, and migration scripts.
2. Implement lifecycle service layer with transaction boundaries and idempotent operations.
3. Build CLI handlers with validation, confirmation prompts, and machine-readable output options.
4. Add configuration template repository, versioning, and selection logic optimized for CLI usage.
5. Instrument auditing hooks and emit structured events for every lifecycle change.
6. Cover main flows with unit tests (service, CLI handler) and integration tests exercising API endpoints used by the CLI.
7. Produce operator documentation and sample scripts for provisioning, updating, and retiring mints from terminals.

## Exit Criteria
- Operators can provision, modify, pause/resume, and retire mints entirely from the CLI.
- Lifecycle transitions are auditable through logs and CLI queries.
- Documentation and automated tests demonstrate the supported terminal workflows.

## Deferred Web Scope (Post-CLI)
- Guided wizard and status history views in the web console, layered on the proven CLI services.
- UI telemetry hooks and layout decisions informed by CLI adoption metrics.
