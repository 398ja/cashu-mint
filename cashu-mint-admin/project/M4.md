# M4 Operational Controls (CLI Phase)

## Overview
Equip administrators with robust CLI tooling to intervene in mint operations. The objective is to perfect terminal-driven safet
y workflows before any web control panels are attempted.

## Deliverables
- Documented key rotation process with automation hooks, approval checkpoints, and minimal service disruption executed via CLI.
- Emergency stop, pause, resume, and drain commands accessible via CLI (`mint ops stop`, `mint ops resume`) with confirmation an
d safety flags.
- Recovery playbooks for resynchronization, data repair, and post-incident verification exposed through CLI guidance and status
polling.
- Background job orchestration for long-running tasks (e.g., rescan, reissue) with observable states surfaced to CLI operators.
- Comprehensive audit logging of manual interventions including rationale, duration, and outcome sourced from CLI events.
- Documentation that walks through incident response, maintenance windows, and recovery drills entirely from terminals.

## Tasks
1. Model operational control workflows (state diagrams, pre/post checks) and codify guardrails.
2. Implement orchestration layer to execute control commands asynchronously with retry/backoff strategies.
3. Add CLI safety features such as `--confirm`, `--schedule`, and automatic impact analysis before execution.
4. Integrate with notification module (M6) to broadcast initiation and completion of critical operations triggered via CLI.
5. Develop integration tests simulating failure scenarios, ensuring rollback paths and audit completeness from CLI invocations.
6. Document runbooks and CLI quick references for common operational scenarios.

## Exit Criteria
- Administrators can trigger and monitor operational interventions exclusively through CLI commands.
- Guardrails, auditing, and notification hooks are validated in terminal-driven simulations.
- Documentation and automated tests demonstrate safe execution and recovery patterns without UI dependencies.

## Deferred Web Scope (Post-CLI)
- UI action panels with confirmation dialogs that mirror the CLI commands once workflows are validated.
- Progress indicators and visual timelines layered onto the web console reusing CLI orchestration telemetry.
