# M3 Navigation, Dashboard, and Shared Data Services

## Objective
Introduce the global navigation experience, shared data fetching infrastructure, and the first production page: the unified dashboard summarising mint health, alerts, and recent activity.

## Scope
- Implement persistent navigation with responsive behaviour, breadcrumbs, and status indicators described in the UX guidelines.
- Establish React Query (or equivalent) data caches, API clients, and polling utilities reused by downstream modules.
- Deliver dashboard cards covering mint overview, alert summaries, recent lifecycle actions, and quick actions.
- Provide initial telemetry instrumentation and accessibility validation for navigation controls.

## Workstreams
### Navigation and Layout
- Build header, sidebar, and breadcrumb components with role-aware visibility and focus management.
- Surface global connectivity and token age indicators sourced from lightweight health endpoints.
- Ensure navigation adapts between desktop and tablet breakpoints while preserving keyboard operability.

### Data Fetching and State Management
- Configure query clients with sensible defaults (stale times, retry policies, error boundaries).
- Implement typed API wrappers and codecs for mint list, alert list, and lifecycle summaries.
- Add background polling with manual refresh and exponential backoff for failure scenarios.

### Dashboard Experience
- Compose dashboard widgets for mint state, outstanding alerts, configuration drafts, and recent actions.
- Implement quick action buttons (create mint, invite operator, acknowledge alert) that deep link to later modules.
- Cover loading, empty, and error states with design-compliant messaging and skeleton components.

## Deliverables
- Production-ready navigation shell and dashboard page wired to live admin REST endpoints.
- Shared services/utilities for query management, polling, and response normalisation.
- Automated unit and integration tests for navigation components, data hooks, and dashboard widgets.

## Acceptance Criteria
- Dashboard renders real data for mints, alerts, and actions with updates at the configured polling interval.
- Navigation items respect role visibility and maintain accessibility targets (WCAG 2.1 AA interactions).
- Shared data layer is reusable by other features and validated through tests executed in `mvn verify`.
