# M7 Alert Operations Panel

## Objective
Provide the alert operations experience for `ALERTS_ADMIN` roles to acknowledge, silence, escalate, and review incidents while keeping dashboard and lifecycle modules in sync.

## Scope
- Build alert listing views grouped by severity with badge counts reflected in navigation and dashboard.
- Implement alert detail panels showing metadata, history, related mints, and suggested runbooks.
- Deliver acknowledgement, silence/unsilence, and escalation workflows with optimistic updates and reconciliation.
- Surface alert history timelines with filtering by timeframe, severity, and mint.

## Workstreams
### Active Alert Management
- Fetch alert feeds via admin REST endpoints with lightweight polling and manual refresh affordances.
- Implement bulk acknowledgement and silence capabilities when authorised by policy.
- Ensure optimistic updates reflect immediately in dashboard widgets and other modules through shared stores.

### Alert Detail and History
- Design detail drawers or pages summarising context, recent actions, and recommended next steps.
- Render historical alerts with filters, pagination, and export options for compliance.
- Integrate links to lifecycle or configuration changes associated with each alert for traceability.

### Notifications and Communication
- Trigger toast/badge updates when new high-severity alerts arrive while respecting accessibility guidelines.
- Provide inline comments or notes if supported, otherwise log acknowledgement rationale in audit trail.
- Emit telemetry for acknowledgement latency, escalation counts, and silence durations.

## Deliverables
- Alert operations UI with list, detail, and action flows wired to admin REST alert endpoints.
- Automated tests covering optimistic updates, polling behaviour, and permission handling.
- Documentation updates explaining alert workflows and linkage with existing CLI processes.

## Acceptance Criteria
- Alert responders can manage active incidents end-to-end with immediate UI feedback and synced dashboard metrics.
- History views provide searchable archives with export/download support and proper role gating.
- Tests verifying actions, polling, and optimistic reconciliation run during `mvn verify`.
