# M5 Configuration Management Center

## Objective
Deliver the configuration workspace that enables operators to inspect revision history, draft updates, preview backend responses, and apply or rollback configuration changes.

## Scope
- Implement revision history list, diff viewer, and detail panes linked to mint context.
- Build configuration editor with form-driven validation, JSON/YAML toggle, and draft persistence.
- Wire preview/apply/rollback flows to admin REST endpoints with inline feedback and audit prompts.
- Support rollback justification capture and linkage to related incidents or alerts.

## Workstreams
### Revision History and Diffing
- Fetch configuration revisions per mint and normalise metadata for quick comparisons.
- Implement collapsible diff viewer with search, syntax highlighting, and section-level navigation.
- Provide export/download options for revision payloads when permitted by policy.

### Drafting and Validation
- Design form experiences for editing structured configuration parameters with schema-aware validation.
- Allow raw JSON/YAML editing with formatting helpers and immediate syntax feedback.
- Persist drafts locally keyed by mint and revision, clearing on publish or explicit discard.

### Apply and Rollback Workflows
- Reuse preview endpoints to render the backend's dry-run response prior to apply.
- Implement rollback modal requiring reason entry and linking to incident references.
- Handle partial success responses, surfacing actionable follow-up tasks and logging errors to telemetry.

## Deliverables
- Configuration center UI components, services, and hooks covering history, diffing, editing, preview, apply, and rollback.
- Test suites verifying validation, draft persistence, diff rendering, and API integration flows.
- Updated documentation referencing configuration workflows and rollback expectations.

## Acceptance Criteria
- Operators can compare revisions, draft changes, preview outcomes, and apply or rollback configurations with confirmations.
- Diff viewer handles large payloads without performance degradation and supports accessibility requirements.
- Automated tests validate success and failure paths and run within `mvn verify`.
