# M8 Activity Log and Settings Experience

## Objective
Implement the aggregated activity timeline and operator settings surfaces, providing audit visibility, export tooling, and personalisation controls outlined in the Phase 2 specification.

## Scope
- Build activity log views combining lifecycle, configuration, operator, and alert actions with advanced filtering.
- Support CSV/JSON export scoped by date range, action type, mint, and operator.
- Implement settings pages for token hygiene guidance, preference management (theme, density, landing page), and documentation links.
- Provide accessibility and internationalisation hooks for copy externalisation across activity and settings modules.

## Workstreams
### Activity Aggregation and Filtering
- Integrate with `/admin/audit` endpoint if available; otherwise synthesise events from existing API responses.
- Normalise event data to drive timeline views, table exports, and cross-module deep linking.
- Implement filters, search, pagination, and bookmarking for frequently used queries.

### Export and Reporting
- Provide CSV/JSON export utilities with progress indicators and error handling.
- Ensure exported data respects role-based visibility and includes correlation identifiers for compliance.
- Log export attempts to telemetry for auditing and capacity planning.

### Settings and Preferences
- Build settings UI for theme selection, table density, and landing page with persistence in storage and server where applicable.
- Display token rotation schedules, expiry warnings, and security guidance with inline documentation references.
- Surface contextual help links to Diátaxis docs relevant to each module.

## Deliverables
- Activity log and settings pages with shared services for event aggregation, export, and preference storage.
- Test coverage for filtering, export success/failure, and preference persistence.
- Documentation updates covering activity log usage, export processes, and available settings.

## Acceptance Criteria
- Activity log renders aggregated events with performant filtering and export capabilities that respect permissions.
- Settings adjustments persist across sessions as expected and provide security-conscious token information.
- Automated tests for activity and settings flows execute as part of `mvn verify`.
