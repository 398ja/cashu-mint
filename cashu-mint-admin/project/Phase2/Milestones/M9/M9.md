# M9 Hardening, Compliance, and Release Candidate

## Objective
Complete quality hardening for the Phase 2 release, covering accessibility, localisation, cross-browser validation, telemetry, and release readiness activities required before pilot rollout.

## Scope
- Execute comprehensive accessibility audits (automated and manual) and remediate findings across modules.
- Finalise localisation infrastructure and ensure copy externalisation with locale switching support.
- Run cross-browser/device testing, performance profiling, and reliability drills (offline mode, retry flows).
- Integrate Playwright/Cypress end-to-end suites, visual regression baselines, and telemetry dashboards.
- Prepare release notes, operator documentation, and pilot enablement assets.

## Workstreams
### Accessibility and UX Quality
- Run axe-core and manual keyboard/screen reader checks on all milestone features, addressing WCAG 2.1 AA gaps.
- Validate focus management, semantic structure, and colour contrast for shared components.
- Collaborate with design to sign off on responsive behaviour and empty/error states.

### Internationalisation and Content
- Externalise remaining strings into locale dictionaries with formatters for dates and numbers.
- Verify locale switching across modules, ensuring fallback behaviour is consistent.
- Coordinate with documentation team to align terminology between UI copy and Diátaxis docs.

### Reliability, Performance, and Observability
- Measure load times, bundle sizes, and API latency; optimise via code splitting and cache tuning where needed.
- Exercise offline/read-only fallbacks and retry logic for major workflows.
- Ensure telemetry emits required events, correlates IDs with backend traces, and feeds observability dashboards.

### Release Enablement
- Finalise Playwright/Cypress smoke suites and integrate into CI gating alongside visual regression snapshots.
- Update admin REST Docker images/Compose configuration to include compiled assets; verify with `docker-compose build`.
- Produce release notes, upgrade checklist, and pilot rollout plan including operator training assets.

## Deliverables
- Accessibility, localisation, performance, and reliability reports with remediation sign-offs.
- Passing end-to-end, accessibility, and visual regression suites wired into CI.
- Release documentation bundle (notes, deployment steps, pilot guide) ready for stakeholder review.

## Acceptance Criteria
- All automated and manual QA suites pass in CI, and critical accessibility issues are resolved.
- Localisation, offline handling, and telemetry behave according to specification and technical analysis expectations.
- Release candidate build packaged with documentation is approved for pilot deployment.
