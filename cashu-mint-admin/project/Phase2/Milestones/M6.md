# M6 Operator Administration Module

## Objective
Ship the operator management experience that lets `USER_ADMIN` roles create, update, deactivate, and manage roles for operator accounts while exposing audit timelines.

## Scope
- Implement operator directory with filtering by role, status, and mint assignment.
- Provide create/edit/deactivate flows including credential reset triggers and role delegation controls.
- Surface audit history per operator including lifecycle actions, login activity, and related incidents where available.
- Enforce role-based permissions and deliver actionable messaging for restricted users.

## Workstreams
### Operator Directory
- Fetch operator lists from admin REST endpoints and normalise data for pagination and searching.
- Implement table/list views with bulk filters, quick search, and status badges.
- Support export of operator listings for compliance review when policy allows.

### Account Lifecycle Flows
- Build dialogs/forms for create and update operations with validation of required metadata and contact details.
- Implement role assignment UI using checklists informed by prefetched role metadata.
- Provide deactivate/reactivate and credential reset flows with confirmation prompts and audit capture.

### Audit Timeline and Contextual Insights
- Render recent actions per operator by aggregating lifecycle/configuration responses or audit endpoint if available.
- Highlight anomalies (e.g., failed logins, privilege escalations) with contextual tooltips and links.
- Ensure read-only roles see limited detail while maintaining traceability requirements.

## Deliverables
- Operator administration pages, dialogs, and supporting services wired to admin REST user endpoints.
- Automated tests covering CRUD flows, role validation, and audit timeline rendering.
- Documentation updates describing operator management within the web client.

## Acceptance Criteria
- `USER_ADMIN` operators can manage accounts end-to-end with role safeguards and audit history available.
- Restricted roles encounter clear messaging and disabled controls when attempting prohibited actions.
- Tests verifying flows, validation errors, and audit rendering execute during `mvn verify`.
